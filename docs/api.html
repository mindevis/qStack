API Documentation

qStack API Gateway — единственный публичный сервис с REST endpoint. Все backend сервисы экспонируют только gRPC (mTLS).

Версионирование API

Версии встроены с первого дня:

  • REST: /v1/vms, /v1/nodes, /v1/images (не /vms)
  • gRPC: package qstack.v1; в определениях protobuf
  • Dashboard и CLI привязаны к v1
  • Breaking changes → deploy v2 alongside v1. Deprecated version работает до миграции всех consumers

gRPC Сервисы

Внутренняя коммуникация между сервисами через gRPC с mTLS. Каждый сервис определяет свои сервисы в proto/ и генерирует код в pkg/grpc/.

proto
package qstack.v1;
option go_package = "github.com/mindever/qStack/pkg/grpc";

// Compute service
service ComputeService {
  rpc CreateVM(CreateVMRequest) returns (CreateVMResponse);
  rpc DeleteVM(DeleteVMRequest) returns (DeleteVMResponse);
  rpc GetVM(GetVMRequest) returns (GetVMResponse);
  rpc ListVMs(ListVMsRequest) returns (ListVMsResponse);
  rpc StartVM(StartVMRequest) returns (StartVMResponse);
  rpc StopVM(StopVMRequest) returns (StopVMResponse);
  rpc MigrateVM(MigrateVMRequest) returns (MigrateVMResponse);
}

// Storage service
service StorageService {
  rpc CreateVolume(CreateVolumeRequest) returns (CreateVolumeResponse);
  rpc DeleteVolume(DeleteVolumeRequest) returns (DeleteVolumeResponse);
  rpc AttachVolume(AttachVolumeRequest) returns (AttachVolumeResponse);
  rpc DetachVolume(DetachVolumeRequest) returns (DetachVolumeResponse);
}

// Network service
service NetworkService {
  rpc CreateNetwork(CreateNetworkRequest) returns (CreateNetworkResponse);
  rpc AllocateIP(AllocateIPRequest) returns (AllocateIPResponse);
  rpc ReleaseIP(ReleaseIPRequest) returns (ReleaseIPResponse);
}

// Billing service
service BillingService {
  rpc CheckQuota(CheckQuotaRequest) returns (CheckQuotaResponse);
  rpc GetUsage(GetUsageRequest) returns (GetUsageResponse);
  rpc GenerateInvoice(GenerateInvoiceRequest) returns (GenerateInvoiceResponse);
}

// Image service
service ImageService {
  rpc GetImage(GetImageRequest) returns (GetImageResponse);
  rpc BuildImage(BuildImageRequest) returns (BuildImageResponse);
  rpc CacheToHosts(CacheToHostsRequest) returns (CacheToHostsResponse);
}

// AI service
service AIService {
  rpc Chat(ChatRequest) returns (stream ChatResponse);
  rpc Advise(AdviseRequest) returns (AdviseResponse);
  rpc Predict(PredictRequest) returns (PredictResponse);
  rpc Diagnose(DiagnoseRequest) returns (DiagnoseResponse);
}

// Backup service
service BackupService {
  rpc CreateBackup(CreateBackupRequest) returns (CreateBackupResponse);
  rpc RestoreBackup(RestoreBackupRequest) returns (RestoreBackupResponse);
  rpc ListBackups(ListBackupsRequest) returns (ListBackupsResponse);
}

Авторизация

JWT Tokens

  • Access token: 15 минут, Refresh token: 7 дней
  • Dashboard: HTTP-only cookie. CLI/API: Bearer header
  • Refresh token rotation — каждый refresh инвалидирует предыдущий токен
  • Session list — пользователь может видеть активные сессии, отзывать конкретные
Go
type Claims struct {
    UserID   string
    TenantID string
    Roles    []string  // ["admin", "tenant_admin"]
    Scope    []string  // ["vm:read", "vm:write"]
    Expiry   time.Time
}

RBAC Roles

РольДоступ
adminВсе tenants, все ресурсы, инфраструктура
superadminВсё + управление другими admin
tenant_adminТолько свой tenant, полный доступ к ресурсам
operatorRead-only свой tenant
service_accountAPI keys, machine-to-machine

Провайдеры аутентификации

  • Password + JWT — локальная аутентификация, bcrypt/argon2, refresh tokens, session revocation
  • OAuth2 / OIDC — SSO через Keycloak, Auth0, корпоративный IdP
  • SAML 2.0 — enterprise SSO (Active Directory, Okta)
  • API Keys — long-lived токены для машин/CI, scoped per tenant, per action

Rate Limiting

API Gateway — единственный публичный сервис. Без rate limiting один tenant или атакующий может перегрузить gRPC бэкенды.

УровеньЛимитГранулярностьНазначение
Global10,000 req/minPer IPЗащита от DDoS
Per-Tenant1,000 req/minPer tenant_idПредотвращение noisy neighbor
Per-User200 req/minPer user_idПредотвращение злоупотреблений
Per-Endpoint50 req/min (write), 500 req/min (read)Per pathЗащита тяжёлых операций (создание VM)
Go
type Limiter struct {
    Global   *token.Bucket  // 10000/min
    PerTenant map[string]*token.Bucket
    PerUser   map[string]*token.Bucket
}

func RateLimit(limiter *Limiter) gin.HandlerFunc {
    return func(c *gin.Context) {
        tenantID := c.GetString("tenant_id")
        if !limiter.Allow(tenantID, c.Request.URL.Path) {
            c.AbortWithStatusJSON(429, gin.H{"error": "rate limit exceeded"})
            return
        }
        c.Next()
    }
}

Circuit Breaker

gRPC вызовы между сервисами имеют circuit breakers для предотвращения каскадных отказов:

  • Closed — обычные вызовы проходят
  • Open — после N последовательных ошибок, мгновенный возврат ошибки (fast fail)
  • Half-open — пробный вызов для проверки восстановления

Конфигурация: api→storage (5 ошибок → open, 30s reset), api→compute (3 ошибки → open, 15s reset).
