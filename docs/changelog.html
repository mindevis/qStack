Changelog

История версий qStack — Cloud VM Orchestrator.

v0.3.0

2025-03-15 Beta

Added

  • VM миграция между хостами (live migration via Libvirt/QEMU)
  • Image caching на гипервизорах (Image service)
  • NATS JetStream streaming для event delivery
  • Certificate management (OpenBao + Vault PKI CA integration)
  • Multi-provider authentication (Password + OAuth2/OIDC + SAML 2.0)
  • K8s Deployment with PDB, HPA для API Gateway

Changed

  • gRPC code generation — unified proto definitions
  • K8s manifests restructured (per-service directories)

v0.2.0

2025-02-01 Alpha

Added

  • Network Service (SDN, IPAM, firewall)
  • Image Service (template management, image conversion)
  • Billing Service (plans, tenants, metering, invoicing, PDF)
  • Backup Service (snapshot, restore, lifecycle)
  • AI Service (assistant, advisor, predictor, auto-heal)
  • Agent — systemd integration, status reporting, heartbeat
  • GlitchTip self-hosted Sentry (error tracking)
  • Observability stack: Prometheus + Grafana + Loki + OpenTelemetry

Changed

  • NATS event-driven architecture (отказ от прямых gRPC calls между сервисами)
  • Monorepo structure — Go workspace (go.work)

v0.1.0

2025-01-15 Alpha

Added

  • API Gateway (REST API, auth, rate limiting)
  • Compute Service (VM CRUD, lifecycle, Libvirt integration)
  • Storage Service (volumes, LVM, qcow2)
  • Dashboard — React admin panel (basic)
  • PostgreSQL multi-schema setup (7 schemas)
  • Monorepo with Makefile orchestration
  • Docker Compose development environment
