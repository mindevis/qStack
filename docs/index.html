Bash

make dev-lint  # golangci-lint + proto lint
make dev-down  # остановка

Changelog

История версий, изменения по фазам реализации проекта

Ключевые особенности

  • Autonomous Hypervisors — каждый хост запускает qstack-agent с local libvirt. При отказе control plane VM продолжают работать
  • Service Independence — каждый сервис — независимый процесс со своей DB схемой и деплоем
  • Live Migration — при сбое гипервизора VM мигрируются на здоровые хосты (zero downtime)
  • Database Isolation — каждый сервис владеет своей PostgreSQL схемой
  • Saga-based Transactions — мульти-сервисные операции через Sagas с компенсирующими действиями
  • PCI-DSS Compliance — строгое разделение Admin и User Dashboard
  • Multi-Tenancy — tenant isolation через RLS, quota enforcement, RBAC
  • AI-Assisted Operations — Advisor, Predictor, AutoHeal, Assistant chat
